short note on why this pass increases adapter-readiness without widening runtime semantics
- The deterministic lane inputs now have one explicit persisted contract that an adapter could emit later, but the runtime still consumes the same `VerticalSliceFixture`, produces the same export bundle/scoreboard/teacher artifacts, and keeps the same fake-backend-only behavior. This decouples fixture definition from in-memory constructors without adding replay ingestion, rollout logic, CLI surface, or broader export semantics.
