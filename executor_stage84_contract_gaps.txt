- current guard shape:

- why indirect:
  - no explicit targeted mutation proves that changing `simulation_seed` changes the simulation request lane or downstream observable output
  - current fake backend stability can mask a broken seed propagation path if outputs remain equal for other reasons

scorer_weights influence
- current guard shape:
  - inferred through frozen scoreboard totals and derived teacher ordering
- why indirect:
  - no test isolates `scorer_weights` as the changed input while holding proposal score signals constant
  - current assertions would catch some outcome drift, but not prove the weights are the cause-path being exercised

- current guard shape:
  - teacher artifact equality inside `assert_fixture_lane_matches_expected_contract(...)`
- why indirect:
  - this is broad artifact equality, not a focused assertion on namespace propagation into seed metadata, synthesis request copy metadata, and persisted artifact header metadata
  - if a future change preserved whole-artifact equality through coupled fixture updates, the specific namespace path would still remain under-explained

anchor metadata propagation
- current guard shape:
  - broad export equality and persisted input round-trip
- why indirect:
  - frozen snapshots do not include anchor metadata
  - no dedicated assertion checks that `anchor_hint.metadata` reaches the exported anchor artifact unchanged

proposal actions / legal_hint / metadata observability
- current guard shape:
  - broad `consumer_export` equality in the parity helper
- why indirect:
  - branch labels are explicitly asserted elsewhere, but `actions`, `legal_hint`, and proposal metadata are not called out by targeted checks
  - a future regression could be harder to diagnose because the failing evidence would be buried inside full export equality

- current guard shape:
  - scoreboard payload equality and golden snapshot totals
- why indirect:
  - total scores are explicit in frozen snapshots
  - score component breakdown is only protected because the whole scoreboard payload is compared, not because component identity/order is asserted directly

teacher label id / ordinal derivation from export_name
- current guard shape:

- why indirect:
  - no targeted assertion isolates the `TeacherLabelId::new(format!(\"{}:teacher:{ordinal}\", ...))` contract

proposal score_signals influence
- current guard shape:

- why indirect:
  - there is no direct mutation showing that changing only one proposal’s score-signals shifts total-score output in the expected narrow way

- why current coverage is only indirect:

  - load teacher artifacts after a run and assert the namespace appears exactly where expected and nowhere else is relied upon
- best home:
  - output snapshot tests or parity helpers

5. proposal actions / legal_hint / metadata surviving into exported branch artifacts

  - focused export reload test asserting one branch’s action list, legal hint, and metadata survive unchanged
- best home:
