chosen parser algorithm plan
- accept only ReplayInput::Memory
- reject ReplayInput::File with replay header parse error: unsupported-input
- reject empty memory label with replay header mapping error
- read header_size i32 at offset 0
- read header_crc u32 at offset 4 as layout evidence only
- do not validate or expose header_crc
- compute and bound header_end = 8 + header_size
- read major_version, minor_version, net_version, and game_type from header data
- enforce exact fixture tuple only:
  major_version=868
  minor_version=32
  net_version=Some(10)
  game_type=TAGame.Replay_Soccar_TA
  ReplayVersion=8
  BuildVersion=241206.55345.468477
- scan top-level properties until None terminator
- reject duplicate top-level property names
- parse selected scalar properties only
- skip non-selected admitted property kinds only by bounded property_size
- skip non-selected top-level ArrayProperty only by bounded property_size
- reject selected ArrayProperty
- reject unknown/unencountered property kinds
- reject UTF-16/negative-length parse_text
- require terminator end to equal header_end
- stop at header_end
- do not read content_crc
- do not parse body, raw-state payloads, replay frames, footer structures, or semantic replay
  events
