# Security Policy

MIMIR is an active research/development project.

Do not publish secrets, credentials, private keys, authentication tokens, or sensitive exploit details in issues or pull requests.

For security-sensitive reports, prefer GitHub private vulnerability reporting when it is available for this repository. If private reporting is unavailable, disclose only the minimum non-sensitive information needed to establish contact and avoid posting working exploit material publicly.

Replay fixtures, generated artifacts, logs, and local machine data must be reviewed before publication.
