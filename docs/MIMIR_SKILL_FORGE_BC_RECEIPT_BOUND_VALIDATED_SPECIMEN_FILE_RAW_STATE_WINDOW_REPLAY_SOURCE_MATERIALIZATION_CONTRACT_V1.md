# MIMIR Skill Forge BC Receipt-Bound Validated Specimen-File Raw-State Window Replay-Source Materialization Contract v1

## A. PURPOSE

### What this pass owns

This pass owns exactly one first narrow contract-definition boundary above:

- `LowBoostRecoveryBcReceiptBoundValidatedSpecimenFileRawStateWindowReplayInputLocatorActualImplementationRealizationResultV1`

It defines:

- the first machine-verifiable replay-source-materialization contract surface for one admitted
  truthful blocked replay-input locator actual-implementation specimen
- the exact per-specimen replay-source-materialization-facing boundary input tuple
- the exact per-specimen replay-source-materialization-facing output boundary
- the exact top-level contract-definition result emitted above that truthful blocked realization

### Why it exists

The reopen-decision boundary below this pass already fixed:

- replay-source materialization must be explicitly reopened
- the next shape must be
  `LowBoostRecoveryBcReceiptBoundValidatedSpecimenFileRawStateWindowReplaySourceMaterializationContractV1`
- the next shape must stay contract-only, family-specific, receipt-bound, below replay-input
  locator logic, below replay parsing, and outside `mimir_export`

What was still missing was the first exact contract surface above that reopen decision:

- what one admitted truthful blocked actual-implementation specimen contributes
- what one honest replay-source-materialization-facing boundary consumes
- what one honest replay-source-materialization-facing boundary exposes without materializing
  replay source

### How it differs from the replay-source-materialization reopen-decision boundary below it

- The lower boundary answers whether replay-source materialization must be reopened.
- This pass does not revisit that answer.
- The lower boundary fixes the narrowest honest next shape.
- This pass defines that shape exactly.
- The lower boundary is docs/artifacts only.
- This pass adds the contract artifact and the minimal machine-verifiable `mimir-skill` contract
  surface justified by that fixed shape.
