# ChatGPT Storage Archive for MIMIR

This directory is a provenance-aware archive of MIMIR-related material discovered in the
user's ChatGPT File Library, including files whose names did not contain `MIMIR`.

## Source classes

- `EXACT_ARCHIVE_COPY`: full source content was available and copied as-is, except path-only portability notes where explicitly stated.
- `CURATED_SOURCE_SNAPSHOT`: the original source was too large / partially retrievable; this file records verified metadata, extracted facts, capability boundaries, and migration relevance.
- `REDACTED_EXTRACT`: source contained unrelated or private content; only MIMIR-relevant material was extracted.
- `CANONICAL_SYNTHESIS`: derived multi-source document. Not an original historical source.

## Reading order

1. `/MIMIR_KNOWLEDGE_GRAPH.md`
2. `/MIMIR_CONTINUE_HERE.md`
3. `/MIMIR_ALL_SOURCES_SUPERBOOK.md`
4. `SOURCE_REGISTRY.md`
5. `VALIDATION_MATRIX.md`
6. Individual source snapshots/copies
7. `migration/HISTORICAL_TO_CURRENT_MAPPING.md`

## Critical rule

Historical implementation is not current production capability.
Design intent is not implementation.
Oracle output is not native MIMIR output.
Fresh GitHub source/tests always win.

## Privacy rule

Raw ChatGPT conversation exports and files containing unrelated personal data are not copied
wholesale into this public repository. They are represented by redacted MIMIR-only extracts.
